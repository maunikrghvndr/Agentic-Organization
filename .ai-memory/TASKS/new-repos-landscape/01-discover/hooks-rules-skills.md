## Notable mechanisms

1. **Blocks come from facts, models only advise.** Canny, custodiet and agent-roast gate on ledger or git facts (a check passed since the last edit; a test was weakened). Model judgments become notes. This keeps gates reproducible and replayable.
2. **A rule ships with its detector and its tests.** gap-trap contracts name the check that finds bypasses; chock policies carry the evals that prove they fire; Andon tests a countermeasure on a failing and a passing case; stop-that-shit publishes Bad/Good cases.
3. **Block messages state the next legal step.** Probity, the LSP kit and claude-bulkhead return the exact command or step to take, parametrized to the file or call that was blocked.
4. **Few rules block; false positives are tracked.** custodiet blocks on 7 of 31 rules and keeps a false-positive ledger; Canny documents "blocks" versus "nags". Compare with `Unverified cannot block`.
5. **Rules are re-tested against evidence.** claude-md-doctor backtests each rule on session history; abide replays real sessions; custodiet re-asks per model whether a rule is still needed; darwin-skill and SkillOpt accept a skill edit only after a behavioural validation run.
6. **Document reviews of instruction text do not predict behaviour.** darwin-skill v3 dropped doc-reading judges for blind comparison of real outputs (its cited papers were not opened here).
7. **Sequencing enforced before dispatch.** skraft blocks an out-of-order subagent dispatch, an unloaded mandatory skill, and progression without artifact + `APPROVED` verdict + verified commit. consort uses a state machine for the same purpose.
8. **Approval bound to a commit sha.** apexyard requires reviewer and named human to approve the exact commit.
9. **Compaction survival by hook.** codex-task-pointer persists a schema-checked goal/next-step pointer and re-injects it at `SessionStart(compact)`, with compare-and-swap writes.
10. **Silent failures of layered rules are lintable.** Unindexed rule file, dangling reference, empty or unparseable `paths:` (vendor doc confirms the last loads the rule unscoped without error).
11. **Size budgets enforced in CI.** meta-llm-charter fails the build when the always-loaded core exceeds a byte limit; agent-rules-books ships three budget tiers per rule set.
12. **Per-host enforcement matrix.** failproofai and karanb192/claude-code-hooks publish what each host can actually block. chock and agents-scaffold compile one policy to the strongest control per host, with the git hook as the floor.
13. **Risk-tiered ceremony.** bearpaws sizes process by consequence rather than diff size and blocks the done-claim on risky work until independent review ran.
14. **Router skill plus dependency table.** Unity installs one index skill that routes to the rest; pstack declares which skills depend on which.
15. **Source-trust questions at tool-call time.** jev-guard asks `user_requested` and `from_untrusted` for each call.
