## Method and limits

- `gh` was unusable (the session's `GH_TOKEN` is rejected as invalid), so discovery used the unauthenticated GitHub REST search API: `curl https://api.github.com/search/repositories?q=<query>&sort=stars&order=desc`. Stars, created and pushed dates below are the values that API returned today.
- Queries run (all star-sorted): `agents.md created:>2026-04-01`; `agent skills created:>2026-04-01 stars:>500`; `claude code skills created:>2026-04-01 stars:>300`; `topic:agent-skills created:>2026-04-01`; `topic:agents-md created:>2026-03-31`; `harness engineering created:>2026-04-01 stars:>300`; `topic:claude-code-plugin created:>2026-04-01 stars:>500`; `topic:agent-skills pushed:>2026-10-01 created:<2026-04-01 stars:>5000`; `topic:claude-skills pushed:>2026-10-01 stars:>5000`; `topic:context-engineering pushed:>2026-09-01 stars:>1500`; `agentic organization in:name,description created:>2026-04-01 stars:>30`; `"agent roles" / "role pack" coding agents created:>2026-04-01 stars:>50`; plus a `repo:` batch for known older libraries.
- Verification per row: the repo appeared in an API search result today AND its README was fetched with HTTP 200 from `https://raw.githubusercontent.com/<owner>/<repo>/HEAD/README.md`. "What it does" and "mechanism" are taken from that README's opening section only (roughly the first 1,000-1,700 characters); deeper files were not read. Nothing was installed or run.
- Not verified: any benchmark, adoption or award claim a README makes about itself (quoted as the repo's claim where used); star counts are raw API values and were not sanity-checked against another source.
- Table B ("majorly updated") rests on push date plus what the README says changed. Push date alone does not prove a major update; rows where the README gave no dated change are marked "push date only".
- Vendor docs: `agentskills.io`, `agents.md` and `developers.openai.com` were blocked by the session's network policy (proxy 403), so no vendor page from those hosts is listed. `https://code.claude.com/docs/en/skills` opened (HTTP 200) but carries no visible date, so it is not listed as "new".
- WebSearch and trending/awesome-list pages were not used; the candidate pool is the GitHub search API only. Awesome-lists seen in results (not opened beyond the search row): `hesreallyhim/awesome-claude-code`, `VoltAgent/awesome-agent-skills`, `ai-boost/awesome-harness-engineering`, `karanb192/awesome-claude-code-mods`.

## Notable mechanisms

1. **Context-free review as a named, structural step.** google/elephant-goldfish-model, sjsyrek/design-council, cloudflare/security-audit-skill and hitianqi/troupe all isolate the reviewer from the author's conversation; Cloudflare adds "a fresh verifier that tries to disprove each candidate".
2. **Behaviour, not document quality, decides whether an instruction change is kept.** darwin-skill v3 (blind comparison of real-run outputs, no-skill baseline, ties to the shorter version, held-out set), microsoft/SkillOpt (validation gate), ponytail (with/without benchmark).
3. **Evidence thresholds for memory edits.** backpass requires verbatim quotes from at least two sessions per edit, under a token budget, human-applied.
4. **Skill lifecycle beyond capture.** autoharness merges, updates and prunes, and only touches what it wrote; contrast with self-learning-skills, which captures immediately without asking.
5. **A gate per rule.** gap-trap pairs every rule with a commit/CI check and adds a "proven red" job; Andon tests each check on a failing and a passing case; agentic-os validates the phase record and states what the validator cannot catch.
6. **Size tiers of the same rules.** agent-rules-books ships nano / mini / full; anti-slop tiers its rules and loads skills only on need.
7. **Hierarchical, self-maintained AGENTS.md.** dox: root index, walk root-to-leaf before editing, update after.
8. **Write once, generate per host.** wshobson/agents adapters + capability matrix + CI regeneration; FerroxLabs symlinks; microsoft/apm manifest and policy; anywhere-agents packs with per-role model/effort config.
9. **Named failure taxonomies.** HERO (Hashing, Edge cases, Rubrics, Overbuild) gives reviewers vocabulary for a specific over-engineering shape.
10. **Stating what the library is not.** repository-harness and anti-slop both declare their non-goals up front; janestreet/agent_skills declares a no-text-PR provenance policy.
