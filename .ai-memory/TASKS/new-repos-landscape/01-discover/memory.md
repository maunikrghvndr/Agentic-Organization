## Method and verification

- **Discovery (V1):** unauthenticated `GET https://api.github.com/search/repositories?q=<query>&sort=stars&per_page=25` on 2026-11-18. Queries: `agent memory created:>2026-04-01 stars:>300`; `claude code memory created:>2026-04-01 stars:>100`; `coding agent memory pushed:>2026-09-01 created:>2026-04-01 stars:>50`; `agent memory git created:>2026-04-01 stars:>50`; `self-improving agent created:>2026-04-01 stars:>100`; `context compaction agent created:>2026-04-01 stars:>30`; `topic:agent-memory created:>2026-04-01 stars:>50`; `topic:claude-code memory in:name,description created:>2026-04-01 stars:>100`; `AGENTS.md memory created:>2026-04-01 stars:>30`. Stars, created and last-push dates in the table are the values that API returned today.
- **Opening (V2):** each repo's README fetched with `curl https://raw.githubusercontent.com/<owner>/<repo>/HEAD/README.md` (HTTP 200 for every row). Mechanism lines are taken from the README text only; no repo code was run or installed.
- **Vendor docs (V3):** WebFetch of the URL in the row.
- **Limits:** `gh` was unusable (invalid token), so `gh search` was replaced by the same REST search endpoint. `github.com` HTML pages, repo-level API (`/repos/...`) and trending pages were blocked by the session proxy, so no trending/awesome-list pass was possible. Mechanisms are README claims, not code-verified; benchmark numbers quoted are the authors' own. Star counts are unusually high for young repos in several cases and were not audited for authenticity.
- **Could not open (therefore NOT listed as candidates):** `developers.openai.com/codex/memories` (host not allowed in this session), `cognition.com/agent-memory-repo` (host not allowed; cited by supermemoryai/memoryrepo as its source technique). Both worth a follow-up fetch once those hosts are allowed.

## Notable mechanisms

1. **Budgeted entry point + pull-on-demand body.** A hard cap on what is always loaded (OKF: 400-token `AGENTS.md`; Claude Code: 200 lines / 25KB; OptMem: `WAKE_LINES` reading budget; memoryrepo: short `MEMORY.md` linking out; tigerless: L0 one-line abstracts then deeper levels). The cap is a *reading* budget, independent of how much is stored.
2. **Append-only log + rebuildable derived view.** Raw record is never edited (OptMem `LOG.txt`, recall `history.md`, beacon JSONL); summaries/indexes are caches that can be deleted and regenerated (OptMem `TREE/`, SQLite indexes in ai-memory, encephalon, agent-memory-vault).
3. **Candidate → reviewed → trusted lifecycle for lessons.** Lessons are proposals until a human accepts them (agentic-stack candidate lessons, llm-wiki-memory "one approval covers one lesson", ownmem "evidence before authority", beacon "reviewed knowledge"). Unreviewed entries are delivered labelled as leads, not facts.
4. **Explicit supersession instead of deletion.** New records must name what they replace (encephalon `--supersedes` every active head of same kind+subject; agentic-stack recall skips superseded lessons; ai-memory "nothing is hard-deleted"; deja-vu `--state rejected`).
5. **Staleness tied to code evidence.** A memory is downgraded when the files it cites change (ownmem evidence drift, deja-vu changed-files notice, aoci `verify` Missing/Orphan/Stale/Unbaselined, entire-brain `verify`).
6. **Negative knowledge as a first-class type.** Failed attempts and abandoned routes are recorded and surfaced *before* the edit (projectmem pre-commit precheck, mainline abandoned routes, self-learning-skills "what didn't work", keep-the-why).
7. **Provenance per fact.** One fact per line with source and date (memoryrepo); epistemic tags `extracted` / `inferred` / `ambiguous` (obsidian-wiki); a consolidation pass must open the cited source to resolve a contradiction.
8. **Compaction re-entry anchors.** A tiny schema-checked "goal + next step" pointer re-injected after compaction (codex-task-pointer); graded context thresholds ending in a forced handoff note returned verbatim (self-compact-pi-agent); `PreCompact` flush (claude-memory-compiler); Anthropic's "assume interruption" protocol; and a measurement harness showing constraints set at task start are what compaction silently loses (agent-context-lab).
9. **Scope separation by path.** Repo knowledge committed with the code vs personal/machine knowledge never committed (Trail `.trail/` vs `~/.trail/`, operator-memory user vs project partition, OKF scope list, claude-smart preference / project skill / shared skill tiers).
10. **Capture triggers and consent classes written down.** When to capture is an explicit list (self-learning-skills), and each action is classed Automatic / Agent-led / Asks first (llm-wiki-memory); applied lessons are announced so their use is auditable (`applied lesson: <title>`, claude-smart skill citations, Storybloq reinforcement counts).
11. **Lint and CI over memory.** Memory files are linted like code (obsidian-wiki `/wiki-lint`, keep-the-why-lint Action, brain.md CLI-only writes, aoci verify gate).
12. **Concurrency guards for shared memory.** Session-scoped claims and CAS revisions prevent one session overwriting another (agent-memory-vault claims/receipts, codex-task-pointer `generation`+`revision`, ai-memory claim-once handoffs).
