## 2. Proposals

Ordered by value for cost. All are additive (no line is removed or compressed), tool-agnostic, and cost 0 bytes in `AGENTS.md`. Dated-addendum sections in `_shared/rules-detail.md` follow the existing precedent at lines 73-95.

### P-9 — Commit by pathspec; check the index first (#19) — recommend adopt

- **Target:** `EngineeringTeam/_shared/rules-detail.md`, section "Git discipline (Boundaries)", new bullet after line 76.
- **Wording:**
  `- Commit by path too (added 2026-11, compound-engineering): when a commit is allowed, name the files (`git commit -m "<msg>" -- <paths>`); a bare `git commit` takes the whole index, including anything the user staged before the session. Before the first commit run `git diff --cached --name-only`: any path outside the phase's `Owns:` is the user's — leave it staged, do not commit it, and say so.`
- **Evidence:** mechanical fact about git, not a measurement; the source pins it with contract tests. The library already has the staging half, so this closes a real hole in an existing rule.
- **Lost by not adopting:** an agent that obeys "stage by path" can still commit the user's unrelated staged work, which is the exact outcome `rules-detail.md:75` forbids.
- **Optional overlay follow-up (separate decision):** none needed; a deny rule cannot tell a bare commit from a pathspec commit reliably (`Settings/README.md:25`).

### P-7 — A recorded, accepted risk is not a Blocking finding (#16) — recommend adopt

- **Target:** `EngineeringTeam/_shared/rules-detail.md`, new dated section after "Rework loop addendum" (line 95).
- **Wording:**
  `## Rework loop addendum — settled decisions (added 2026-11, compound-engineering)`
  `A finding that only restates a risk or choice the task file's Decisions record as accepted by the user is reported once as Non-blocking, quoting the Decision line. It may be Blocking only when the reviewer's evidence (`Verification: Confirmed` or `Probable`) shows the decision cannot work, builds the wrong thing against an `AC-n`, or is destructive; the finding then names the Decision line it reopens and the user decides. A mandatory-security finding is never downgraded by this rule.`
- **Evidence:** Measured, one case in the source (a reviewer returned `blocked` on 3 of 3 runs over an explicitly accepted risk); the exact source file was not pinned in the deep read, so treat as Anecdotal-plus.
- **Lost by not adopting:** with fresh-context reviewers fed only the diff and Decisions, an accepted trade-off can burn all 3 rework rounds and end in a ROADMAP Blocked that the user already answered.
- **Note for the security pass:** the last sentence is there so this cannot be used to wave through a security finding via a Decisions line.

### P-2 — Enforce before you write prose, and prove the check (#2) — recommend adopt

- **Target:** `EngineeringTeam/_shared/memory.md`, new bullet after line 27 ("Admission and supersession").
- **Wording:**
  `- **Cheapest durable form (added 2026-11, compound-engineering).** A lesson that passes admission takes the first form that holds, in order: (1) one owner, one way — report the duplicate paths, never consolidate unasked; (2) a check (test, lint or analyzer rule) in the project's existing tooling; (3) one line in the constitution or a Hard Rule; (4) a memory or `LESSONS` line. A new check counts only with two Evidence rows: it passes on the current tree, and it fails on the defect's shape in a throwaway copy or fixture — the working tree never holds the defect. A check that cannot be shown failing is not a check; fall through to (3).`
- **Evidence:** No measured evidence in the source for how often each rung is chosen. The library's own lessons support the second half directly (`LESSONS.md` 2026-09-29: "A check whose population is empty must report NOT MEASURABLE"; "Validators tested in isolation pass forever").
- **Lost by not adopting:** the library names the enforced destinations (`enforced by <check>`, `Enforced by:` in the constitution template) but leaves the order to judgment, so lessons default to prose that nothing enforces.
- **Constraint check:** rung (2) may add a lint rule or test; adding a *dependency* for it stays ask-first.

### P-1 — Counterfactual admission test for a lesson (#1) — recommend adopt

- **Target:** `EngineeringTeam/_shared/rules-detail.md`, section "Self-Learning — when to write a lesson", new paragraph after line 38. (Not `LESSONS.md` itself: per the library's own lesson, the control should not live only inside the file it protects.)
